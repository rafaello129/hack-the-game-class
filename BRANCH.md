# Rama `clase/vulnerable`

Esta rama contiene **errores de seguridad intencionales** para una práctica guiada.

## Tu misión

Sin mirar la rama `clase/seguro`, intenta descubrir:

- qué datos controla el navegador;
- qué información puede inspeccionarse en DevTools;
- qué valores pueden modificarse desde Local Storage;
- si existe información que se está tratando como "secreta";
- si alguna autorización depende únicamente del frontend.

## Herramientas permitidas

Dentro de este proyecto local:

- DevTools → Console;
- DevTools → Sources;
- DevTools → Application → Local Storage;
- barra de direcciones del navegador.

No utilices la práctica para atacar sitios, cuentas o sistemas externos.
