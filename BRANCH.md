# Rama `clase/inicio`

Esta es la versión recomendada para comenzar la clase.

## Orden sugerido

1. Ejecuta el juego sin abrir demasiado código.
2. Explora la estructura de escenas.
3. Modifica `src/game/config.ts`.
4. Revisa `src/game/logic.ts`.
5. Ejecuta los tests.
6. Después cambia a `clase/vulnerable`.

## Idea principal

El objetivo al inicio no es entender Phaser completo.

Busca solamente la relación:

```text
valor del código
      ↓
comportamiento visible
```

Esta rama no incluye las vulnerabilidades intencionales de la práctica.
