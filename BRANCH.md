# Rama `clase/inicio`

Esta es la versión recomendada para comenzar la clase.

Orden sugerido:

1. Ejecuta el juego sin mirar demasiado código.
2. Explora la estructura del repositorio.
3. Modifica `src/game/config.ts`.
4. Completa las primeras Issues.
5. Después cambia a `clase/vulnerable` para la parte de ciberseguridad.

Aquí todavía no están añadidas las vulnerabilidades intencionales de la práctica.
