# Retos para alumnos

La regla de trabajo es:

> cambia una cosa, ejecuta y observa.

## Nivel 1 — Explorar

Encuentra:

- el archivo que inicia Phaser;
- el archivo con valores fáciles de cambiar;
- la escena del menú;
- la escena donde ocurre el juego;
- la escena final.

## Nivel 2 — Modificar

Sin cambiar la estructura del proyecto:

1. Haz al jugador más rápido.
2. Haz que cada moneda valga más puntos.
3. Empieza con más vidas.
4. Cambia la meta de puntuación.
5. Añade más enemigos.
6. Cambia al menos dos colores.

## Nivel 3 — Comprender

Responde:

- ¿Qué diferencia hay entre `create()` y `update()`?
- ¿Por qué el juego está dividido en escenas?
- ¿Qué parte controla el teclado?
- ¿Qué parte detecta una moneda?
- ¿Qué función reduce las vidas?

## Nivel 4 — Seguridad

Cuando el profesor indique usar `clase/vulnerable`:

- abre DevTools;
- inspecciona Local Storage;
- busca información que parezca secreta;
- identifica alguna decisión importante que dependa únicamente del navegador;
- intenta explicar por qué ocultar algo no equivale a protegerlo.

La práctica se limita exclusivamente a este proyecto local.

## Nivel 5 — Defender

Para cada problema encontrado responde:

1. ¿Qué controla el usuario?
2. ¿Qué dato estamos confiando?
3. ¿Qué debería validar un backend?

No se acepta "ocultar mejor el JavaScript" como solución de seguridad.
