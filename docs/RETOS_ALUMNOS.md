# Retos para alumnos

No necesitas entender todo el proyecto. Trabaja por observación: cambia una cosa, ejecuta y comprueba qué ocurrió.

## Nivel 1 — Explorar

- Encuentra el archivo que contiene los valores fáciles de modificar.
- Identifica dónde arranca el juego.
- Encuentra la escena principal.
- Explica con tus palabras qué hace `package.json`.

## Nivel 2 — Modificar

- Haz al jugador más rápido.
- Cambia los puntos de una moneda.
- Cambia las vidas iniciales.
- Cambia la puntuación necesaria para ganar.
- Cambia al menos dos colores.
- Prueba una cantidad diferente de enemigos.

## Nivel 3 — Razonar

- ¿Qué parte representa datos?
- ¿Qué parte representa reglas?
- ¿Qué parte responde al teclado?
- ¿Qué cambia cada frame?
- ¿Qué ocurre cuando el jugador toca un enemigo?

## Nivel 4 — Seguridad

Cuando el profesor indique cambiar a `clase/vulnerable`:

- Abre DevTools.
- Investiga qué información guarda el navegador.
- Busca información que parezca secreta.
- Identifica una decisión importante tomada únicamente en frontend.
- Explica por qué “oculto” no significa “protegido”.

No ataques sitios, cuentas o sistemas externos. La práctica está diseñada exclusivamente para este proyecto local.

## Nivel 5 — Defender

Propón una solución para uno de tus hallazgos.

No basta con decir “ofuscar el JavaScript”. Piensa qué parte debería ser validada por un sistema que el usuario no controle.
